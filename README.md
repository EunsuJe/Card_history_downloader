# 법인카드 내역 조회·다운로드 (Chrome 확장 프로그램)

한화 그룹웨어 **포털(hwenc.cleverse.kr) → E-Accounting(ea.hwenc.com)** 에서 법인카드 내역 조회·다운로드를 자동 반복하는 Chrome 확장(MV3)입니다.

## 자동 동작 흐름

```
① 포털 진입      시작 탭이 포털이면: 로그인 화면이면 "로그인 대기" (수동 로그인 후 자동 계속)
                 로그인되어 있으면 <button>E-Accounting</button> 클릭
② 창 전환        새 탭/창으로 열리는 E-Accounting을 자동 감지해 작업 탭으로 전환
③ 메뉴 이동      "개인 경비" → "법인카드 경비 신청" (이미 화면이 열려 있으면 생략)
④ 조건 입력      상태 목록을 '전체'로 선택 → 시작일자(이번 달 1일)·종료일자(오늘) 입력
⑤ 조회·다운로드  "조회" 클릭 → 결과 대기 → "엑셀" 클릭 → 다운로드 완료 감지
⑥ 반복           다음 기간으로 ④~⑤ 반복 → 전체 완료 시 자동 중지
```

- 시작 위치는 유연합니다: **포털 탭**에서 시작하면 ①부터, **E-Accounting 탭**에서 시작하면 ③부터 진행합니다.
- 팝업에서 시작일/종료일을 지정하고 **분할 단위(없음/1개월/3개월)** 를 고르면 그 단위로 나눠 연속 다운로드합니다 (팝업에 미리보기 표시).
- 버튼은 화면 문구(`E-Accounting`, `조회`, `엑셀`), 날짜 입력란은 `aria-label="시작일자"/"종료일자"`로 찾습니다 — `data-ndid`(UUID)는 세션마다 바뀔 수 있어 사용하지 않습니다.
- 로그인 비밀번호는 **저장·입력하지 않습니다** (로그인은 사용자가 직접, 확장은 대기 후 이어서 진행).
- iframe 화면도 자동 탐색하며, 실행 로그를 팝업에 남기고 CSV로 내보낼 수 있습니다. 모든 데이터는 브라우저 내부에만 저장됩니다.

## 설치

1. 압축을 푼 `card-history-downloader` 폴더를 원하는 위치에 둡니다.
2. Chrome 주소창에 `chrome://extensions` 입력 → 우측 상단 **개발자 모드** ON.
3. **압축해제된 확장 프로그램을 로드** → 이 폴더 선택.
4. 포털(hwenc.cleverse.kr) 또는 E-Accounting 화면 탭에서 툴바의 확장 아이콘 클릭 → 기간 설정 → **시작**.

## 화면별 인식 방법 (`selectors.js`)

| 요소 | 찾는 방법 |
|------|-----------|
| 포털 로그인 화면 | `input[type="password"]` 표시 여부 → 대기 상태 진입 |
| E-Accounting 버튼 | 문구가 `E-Accounting`(대소문자 무관)인 `<button>` |
| 개인 경비 / 법인카드 경비 신청 | 화면 문구 정규식 (`site.menuPath`) |
| 상태 드롭다운 | `input[aria-autocomplete="list"]` 중 첫 번째 → 목록을 열어 '전체' 클릭 (실패 시 직접 입력+Enter) |
| 시작일자 / 종료일자 | `input[aria-label="시작일자"]` / `input[aria-label="종료일자"]` — 형식은 기존 값 기준 자동 맞춤 |
| 조회 / 엑셀 버튼 | 문구가 정확히 `조회` / `엑셀`인 요소 (비활성 표시가 30초 이상 남으면 강제 클릭) |

## 처음 실행할 때 확인하세요

1. **포털에서 시작**을 누르고 로그인하면 로그에 "E-Accounting 버튼 클릭 — 창 열림 대기" → "E-Accounting 창 감지"가 이어지는지 확인하세요.
2. **날짜 반영** — `시작일 미반영(...)` 경고가 뜨면 `site.dateFormat`에 형식 지정 (예: `'YYYYMMDD'`).
3. **상태 '전체'** — 바뀌지 않으면 `site.selectIndex`를 조정하세요.
4. **엑셀 클릭 후 확인창**이 뜨면 그 창의 HTML을 보내주세요 — 자동 확인을 추가합니다.

## 자동화가 안 될 때

- **E-Accounting 창이 안 열림**: 180초 후 중지됩니다 — 포털 홈 화면에서 버튼이 실제로 보이는지 확인하고, 버튼 문구가 다르면 `portal.eaButton` 정규식을 수정하세요.
- **SSO 중간 화면에서 멈춤**: 포털→E-Accounting 사이에 추가 인증(예: OTP)이 있으면 수동으로 완료해 주세요 — 확장이 해당 탭을 감지하면 이어서 진행합니다.
- **날짜를 달력 클릭으로만 넣는 화면**: 값 입력이 무시되면 로그에 경고가 남습니다 — 그 경우 화면 HTML을 공유해 주세요.
- **키보드보안/입력방지 모듈**이 있는 화면은 자동 입력이 차단될 수 있습니다.
- **버튼이 여러 개로 보임**: 확장이 중지하며 안내합니다 — `selectors.js`의 `searchBtn`/`excelBtn`에 셀렉터를 지정하세요.
- **`manifest.json`의 `host_permissions`**: iframe 구성 대응을 위해 `<all_urls>`을 유지합니다. 사내 보안 정책상 좁혀야 하면 포털·E-Accounting 도메인을 모두 포함해야 합니다.

## 주의

- 회사 전산자원 사용 지침·보안규정에 따라 **허용된 용도로만** 사용하세요.
- 무인 실행 시 Chrome 설정의 **"다운로드 시 각 파일의 저장 위치 확인"** 을 끄는 것이 좋습니다.
- 실행 중에는 대상 탭(포털·E-Accounting)을 닫거나 다른 페이지로 이동하지 마세요.
